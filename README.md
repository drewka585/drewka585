# Drew Coleman

I run [DeeCe Digital](https://deecedigital.com) in Rochester, NY. I build the systems that put sales calls on a calendar: cold email, Meta and Google ads, and the AI automation that connects them to the rest of the business.

Most of my code lives in private client repos. What I can show is below.

## What I build

- **Cold email programs.** Domains, mailboxes, verified lead lists, copy, AI reply handling and a booking flow. One program for a financial advisory firm reached 25,628 people and drew 1,506 positive replies. 157 people booked a sales call while it ran.
- **Booking and sales apps.** A round-robin booking app in Next.js and Supabase for a team of advisors. It records which campaign each call came from.
- **Command centers.** One Next.js and Postgres app that a property management company runs its whole operation from. It replaced 14 separate systems.
- **AI agents and automation.** Claude Code agents, Make, n8n, Airtable and API integrations for lead qualification, research, proposals and reporting.
